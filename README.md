# IronSoul Training — standalone React app

This is an independent Vite + React app. It has no Lovable dependencies, routes, or asset URLs.

## Run it

```sh
npm install
npm run dev
```

## Add the original images

Put the image files in `public/assets/` with these exact names:

- `ironsoul-logo.png`
- `ironsoul-phoenix.png`
- `ATHLETE_PHOTO.png` (already added)

Until then, the app deliberately shows styled placeholders instead of loading anything from Lovable.
